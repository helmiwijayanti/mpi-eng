# How to Pay using S Pay Later

Media pembelajaran interaktif Bahasa Inggris, SMP Kelas 9 / Fase D, materi Procedure.
Model: Pembelajaran Mendalam. Alokasi: 3 x 40 menit.
Dibuat untuk Bu Helmi.

## Cara memakai (online maupun offline)

Buka `index.html` langsung dari folder ini (klik dua kali), atau unggah seluruh
folder ke hosting statis apa pun (misalnya GitHub Pages). Tidak perlu build,
tidak perlu server, tidak ada CDN dan tidak ada panggilan jaringan wajib.
Semua CSS, JavaScript, dan ilustrasi SVG bersifat lokal.

## Isi: 13 tahap Learning Journey

1. Cover (`index.html`)
2. Tujuan (`tujuan.html`)
3. Apersepsi (`apersepsi.html`)
4. Asesmen Awal (`asesmen-awal.html`, 4 soal)
5. Materi 1 (`materi-1.html`)
6. Materi 2 (`materi-2.html`)
7. Arena Interaktif (`arena.html`: Kalkulator Tenor + Temukan Kesalahan)
8. Tantangan Bermain (`tantangan.html`: Susun Langkah, 120 detik)
9. LKPD Digital (`lkpd.html`: bisa diisi, disalin, dicetak)
10. Kuis (`kuis.html`, 8 soal, minimal 1 HOTS, label hijau/kuning/merah)
11. Refleksi (`refleksi.html`, 4 pertanyaan)
12. Asesmen Akhir (`asesmen-akhir.html`, 8 soal)
13. Kesimpulan & Penutup (`penutup.html`)

Progres, jawaban, dan refleksi murid tersimpan otomatis di perangkat
(`localStorage`) sehingga murid bisa keluar dan lanjut lagi.

## Untuk guru

`guru.html` berisi kunci jawaban, pedoman penilaian, diferensiasi, dan rubrik
komunikasi. File ini sengaja TIDAK ditautkan dari navigasi murid.

## Catatan isi

Perhitungan cicilan di media ini disederhanakan tanpa biaya admin/bunga
(harga dibagi tenor) agar murid kelas 9 dapat menghitungnya. Di aplikasi
nyata, selalu periksa biaya admin, bunga, dan denda keterlambatan, dan
diskusikan pemakaian "bayar nanti" dengan orang tua.

## Akses multi-perangkat

Responsif dari lebar sekitar 360 px, area sentuh minimal 44 px. Pada lebar
1400 px ke atas, mode layar besar aktif otomatis: font membesar, tombol
minimal 72 px, dan navigasi dapat memakai tombol panah + Enter (remote presenter).

## Warna dan font

Primer #1b2a4a, sekunder #22d3ee, aksen #f5b301, latar putih. Satu keluarga
font sistem, tanpa unduhan eksternal.
